# FullMeta documentation

FullMeta opens documents using their interpreting schemas. The workspace, Schema Editor and applications provide the controls and documentation appropriate to the open document.

## Using FullMeta

- [Workspace and menus](workspace.md): open documents, navigate projects, use layouts and find contextual Help.
- [Schema Editor](../schema-editor/docs/README.md): create and edit interpreting schemas.
